# HackHeist 2.0 — Landing Page

A dark, developer-focused landing page inspired by the **Money Heist** aesthetic, created as a reference project for **HackHeist 2.0**.

The design combines a cinematic visual style with a clean event-focused layout, highlighting the hackathon details, countdown, call-to-action, and important event information.

## ✨ Features

- Money Heist-inspired visual direction
- Dark developer-focused interface
- Responsive landing page
- Hero section with event branding
- Event date and venue information
- Live countdown section
- Devfolio application CTA
- Event statistics and highlights
- Responsive layout for mobile and desktop
- Custom SVG icons and visual assets

## 🛠️ Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling, layout, animations and responsive design
- **JavaScript** — Interactive elements and countdown functionality
- **Lucide Icons / SVG assets** — Interface icons

## 🎨 Design Direction

The visual identity takes inspiration from the **Money Heist** theme while keeping the interface suitable for a technical hackathon.

The design focuses on:

- Strong typography
- Dark backgrounds
- High-contrast text
- Subtle Google-inspired accents
- Cinematic imagery
- Minimal but meaningful UI elements

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/keshavkumbhaj/gdg_hackheist.git
```

Move into the project directory:

```bash
cd gdg_hackheist
```

Then open `index.html` in your browser.

For development, you can also use the **Live Server** extension in VS Code.
